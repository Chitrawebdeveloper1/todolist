# To-Do List ✅

A simple and user-friendly to-do list app built with HTML, CSS, and JavaScript.

## 🚀 Tech Stack
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Add, delete, and mark tasks as completed
- Real-time UI updates
- Clean and minimal design
- Responsive layout
